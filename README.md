# מערכת לחישוב החזר מס והכנת טופס 135

אפליקציית Next.js לחישוב החזר מס שנתי לשכירים בישראל והכנת מילוי טופס 135 (דוח שנתי מקוצר לשכיר) לפי כללי מס הכנסה לשנים 2024–2025.

## תכונות

- **אשף 6 שלבים**: פרטים אישיים → בן/בת זוג → ילדים → טופסי 106 → הכנסות נוספות → תוצאות
- **מנוע חישוב מלא**:
  - מדרגות מס 2024–2025 (זהות — הוקפאו)
  - מס יסף (3% מעל 721,560 ₪)
  - נקודות זיכוי כולל ילדים לפי גיל ותפקיד הורה
  - זיכוי קצבה לעמית שכיר (35% עד 7% מההכנסה המבוטחת)
  - זיכוי ביטוח חיים (25%) ותרומות סעיף 46 (35%)
- **מיפוי שדות טופס 135** — כל שדה עם המספר הרשמי
- **התראות סיכון**: חוב, החזר חריג, מסמכים חסרים
- **רשימת מסמכים** לצירוף בהגשה
- **ייצוא JSON** עם כל החישוב

## הרצה מקומית

```bash
npm install
npm run dev
# פתח http://localhost:3000
```

## בדיקות

```bash
npm test
```

## מבנה

```
app/                  # Next.js App Router
  layout.tsx          # RTL + עברית
  page.tsx            # נקודת כניסה
  globals.css         # סגנון בסיסי + Tailwind
components/
  Wizard.tsx          # שלבי האשף
  steps/              # רכיב לכל שלב
lib/
  constants.ts        # מדרגות מס, נקודות זיכוי, רף יסף
  types.ts            # טיפוסים
  taxCalculator.ts    # מנוע החישוב
  creditPoints.ts     # נקודות זיכוי
  form135.ts          # מיפוי שדות טופס 135
  checklist.ts        # רשימת מסמכים
  __tests__/          # בדיקות מול תרחיש הדוגמה
```

## הערות חשובות

- החישוב הוא **הערכה בלבד** — לפני הגשה יש לאמת בסימולטור הרשמי של רשות המסים
- אם החישוב מצביע על **חוב** — אל תגיש 135! הגשה עלולה לחשוף לדרישת תשלום
- האפליקציה אינה מהווה ייעוץ מס מקצועי
- המדרגות הוקפאו ל-2025 (זהות ל-2024); לעדכון שנים אחרות יש לערוך את `lib/constants.ts`
